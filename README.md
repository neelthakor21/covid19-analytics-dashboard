## Overview

The COVID-19 Analytics Dashboard is a data analytics project built using Streamlit, Pandas, and Plotly. Using the Johns Hopkins University COVID-19 dataset, the application transforms raw pandemic data into interactive visualizations and actionable insights through data cleaning, transformation, feature engineering, and exploratory data analysis (EDA).

The dashboard enables users to explore global and country-level trends, monitor case growth, analyze mortality patterns, compare regions, and visualize geographic distributions through an intuitive web-based interface.

---

## Technical Highlights

### Data Processing

* Data ingestion from Johns Hopkins COVID-19 datasets
* Data cleaning and preprocessing
* Handling of missing and inconsistent values
* Dataset reshaping and normalization
* Aggregation of country-level and global metrics

### Feature Engineering

* Growth rate calculations
* KPI generation
* Trend-based metrics
* Comparative country statistics

### Exploratory Data Analysis (EDA)

* Time-series trend analysis
* Country comparison analysis
* Correlation analysis
* Geographic pattern exploration
* Statistical summarization of key indicators

### Data Visualization

* Interactive Plotly visualizations
* Choropleth world maps
* Time-series charts
* Scatter plots with trendlines
* Comparative analytics dashboards
* Dynamic KPI cards

### Dashboard Development

* Multi-page Streamlit architecture
* Interactive filtering and exploration
* Responsive dashboard design
* Real-time visualization updates
